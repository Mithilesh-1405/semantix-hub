# SEMANTIX 
Semantic Resume Analysis & PDF Search Platform

## What is Semantix?
**Semantix** is a semantic document intelligence platform that helps users optimize resumes, discover meaningful insights from PDF documents, and track their document interactions. It analyzes resumes to match against a job description and provides a score out of 100, while its semantic search engine retrieves relevant information based on meaning rather than exact keyword matches. The platform also maintains user activity history, enabling easy access to past searches and analyses for a more productive and personalized experience.

## Features

- Resume Analysis and performance score
- Semantic Search Across PDF Documents
- Meaning-Based Information Retrieval
- User Activity and Search History Tracking
- Fast and Interactive Web Interface
- Secure User Authentication
- Google auth for easier signup/signin

## How does Semantix work?
There are two main features in Semantix

### 1. Resume Analysis

- User uploads a resume.
- Semantix analyses the resume and gives a performance score out of **100**.
- The higher the score, the better.

### 2. PDF Search

- User uploads a PDF.
- Semantix searches the meaning of the search query in the PDF.
- The matching text is highlighted in the PDF.
